What a website still cannot read

Even with every permission granted, browsers enforce hard security boundaries.

  • Phone number & installed appsNot exposed. No browser API reveals your phone number or app list.
  • Contacts, SMS & call historyNot a web API. Only native apps with OS permission can access these — a web pop-up claiming to read them is always a lie.
  • Device serial numberNot provided to websites. At most, browsers share broad platform hints.
  • Full file systemWebsites can only access files you explicitly pick in a file dialog — not your whole storage.
  • Other websites you've visitedModern browsers prevent cross-origin history sniffing.
  • Camera & microphone stream (without permission)Requires explicit browser prompt — which you just saw. Always check the URL before granting it.

🛡️ How to protect yourself

  • Urgency + big prizes = manipulation. Slow down whenever a site pressures you with countdowns or free rewards.
  • Check the URL before anything else. Scammers use look-alike domains (e.g. paypa1.com, g00gle.com).
  • Camera, mic, and location are powerful. Never grant them to a site you didn't intentionally open and trust.
  • No web page can read your contacts, files, or call history — that claim is always a scam.
  • If you granted location to a suspicious site, the attacker now knows where you physically are.
  • If something feels off, close the tab immediately and go directly to the real official website.
