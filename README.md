# Cyber-Security-Awareness

A static phishing-awareness demo. The dramatic “YOU'VE BEEN HACKED!” headline is
simulated; browser details and coarse hardware estimates are displayed locally
and are not collected or sent. The page also explains data that ordinary
websites cannot freely access, such as your phone number or installed apps.

## Publish with GitHub Pages

1. Push this repository to GitHub with the `main` branch.
2. In the repository, open **Settings → Pages** and set the build and deployment
   source to **GitHub Actions**.
3. Push to `main` (or run the **Deploy static site to GitHub Pages** workflow
   from the Actions tab). The workflow publishes `index.html`.
4. Open the URL shown in the workflow’s deployment environment.

The page has no analytics, external scripts, cookies, or data-collection
services. GitHub Pages hosting itself may process ordinary web request data.
